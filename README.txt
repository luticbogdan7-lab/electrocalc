ElectroCalc — aplicație web educațională

PUBLICARE GRATUITĂ CU GITHUB PAGES
1. Intră pe https://github.com/ și creează un cont gratuit sau autentifică-te.
2. Creează un repository nou, de exemplu electrocalc. Poți seta Public.
3. Apasă Add file → Upload files și încarcă index.html din acest folder.
4. Apasă Commit changes.
5. Intră în Settings → Pages.
6. La Build and deployment, alege Deploy from a branch; branch: main; folder: /(root); apasă Save.
7. După publicare, linkul va fi de forma https://NUME-UTILIZATOR.github.io/electrocalc/
   Înlocuiește NUME-UTILIZATOR cu numele tău GitHub. GitHub Pages poate avea nevoie de câteva minute.

PERSONALIZARE
În index.html, caută textul:
[Numele și Prenumele studentului]
și înlocuiește-l cu numele tău complet înainte de publicare.

DESCRIERE PENTRU PREDARE
ElectroCalc este o aplicație web educațională destinată studenților FEIE, UTM.
Aplicația permite calcularea tensiunii, intensității curentului și rezistenței
conform legii lui Ohm, calcularea puterii electrice și conversia unităților
uzuale pentru tensiune, curent, rezistență și putere. Interfața este adaptată
pentru calculator și telefon. Aplicația este realizată în HTML, CSS și JavaScript
și poate fi găzduită gratuit prin GitHub Pages.
